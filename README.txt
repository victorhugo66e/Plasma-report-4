تطبيق PWA: تقرير البلازما الشهري لمشفى قطنا الوطني

النشر:
1. ارفع index.html وmanifest.json وsw.js إلى استضافة تدعم HTTPS (مثل Netlify).
2. افتح رابط الموقع على الهاتف.
3. من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
4. أدخل مجموعات البلازما واحفظ التقرير. للطباعة اختر «طباعة / حفظ PDF».

الأرشيف محفوظ محلياً في المتصفح. صدّر نسخة احتياطية دورياً. عند تغيير الاستضافة/الجهاز قد لا تنتقل البيانات تلقائياً.
